# Knowledge-base
A repository designed for hermes agent

## 📚 初中知识库导航索引 (Knowledge Base Index)

本仓库为 Hermes AI 智能体专用的知识库索引文件。包含初中各学科的教学资料与知识点拆分文档。

---

### 🤖 AI Agent 读取指南 (Instructions for Hermes)

1. **定位方式**：当回答用户问题时，请优先参考下方【文件目录结构】找到对应学科与章节的具体路径。
2. **文件获取**：根据目录中的相对路径读取对应的 PDF/Markdown 文件内容。
3. **学科覆盖**：目前主要包含 **初中数学** 与 **初中英语（2026春人教版八年级下册）** 资料, 其中英语部分按顺序是1-9单元以及额外阅读，语法还有单词表和不规则动词表。
